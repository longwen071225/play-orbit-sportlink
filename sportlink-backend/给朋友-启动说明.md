# SportLink Motion OS · 启动说明（发给朋友的版本）

儿童上门体育预约平台：**FastAPI 单后端（端口 8100，已内置构建好的教练端/管理端前端）+ 双 AI Agent + 浏览器本地姿态识别训练页**。

> 本包不含任何密钥（`backend/.env` 已移除）。没有 API Key 时自动进入 mock AI 模式，离线也能跑通完整业务链路。

## 方式一：只跑 Python 后端（最快，前端已构建好）

```powershell
cd SportLink-Motion-OS
python -m venv .venv
.\.venv\Scripts\pip install -r backend\requirements.txt
.\.venv\Scripts\python -m backend.run
```

打开：

| 地址 | 内容 |
|---|---|
| http://127.0.0.1:8100/static/coachapp/index.html | **教练端 + 管理端（SportLink Motion OS 新版界面）** |
| http://127.0.0.1:8100/static/coachapp/index.html#/admin/dashboard | 管理端（SPORTLINK CONTROL CENTER） |
| http://127.0.0.1:8100/demo | 演示控制台（家长预约入口） |
| http://127.0.0.1:8100/motion-coach | AI 运动陪练（摄像头姿态识别） |
| http://127.0.0.1:8100/docs | Swagger 全部接口 |

**演示账号**（密码统一 `demo123456`）：教练 `13900000001`、管理员 `13700000000`、家长 `13800000001`。
打开教练端/管理端会自动按角色静默登录，无需手动输入。

> 如果页面白屏：按一次 **Ctrl + F5** 强制刷新（会自动清理旧版 Service Worker 缓存）。

## 方式二：前端开发模式（改代码热更新）

```powershell
# 终端 1：后端
.\.venv\Scripts\python -m backend.run

# 终端 2：前端（需要 Node 20+）
cd coach-admin
npm install
npm run dev        # http://localhost:5173/static/coachapp/
```

前端 dev 已配置代理：`/api → http://127.0.0.1:8100`，无需改任何配置。

## 重新构建前端（可选）

```powershell
cd coach-admin
npm run build      # 产物在 coach-admin/dist
# 部署：把 dist 内容复制到 backend/static/coachapp/
```

## 数据说明

- `prisma/dev.db`：随包附带一份演示数据（3 位教练、多位学员、各状态订单、成长星图记录），开箱即可看到完整界面。
- 想重置演示数据：`.\.venv\Scripts\python -m backend.starfit.seed --reset`
- 接真实百炼：复制 `backend/.env.example` 为 `backend/.env`，填入 `SOLOPILOT_DASHSCOPE_API_KEY`。
