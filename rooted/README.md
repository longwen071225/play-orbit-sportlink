# ROOTED — Good by nature

A responsive botanical care concept based on the Forest / Sage design brief. Buildless HTML, CSS, and JavaScript; no install or build step.

## Preview

From this directory run `python3 -m http.server 4173 --directory dist`, then open http://localhost:4173.

## Included

- Local Anton and Inter fonts; exact Forest, Sage, Olive, Cream, and Moss tokens.
- Fixed fractal-noise texture at 4%, rounded section containers, animated hero letters, floating photographs, scroll parallax, and intersection reveals.
- User-supplied packaging photograph as a full-bleed hero background; seamless left-to-right 48-second loop with a sage readability overlay and reduced-motion fallback.
- Circular 3D image carousel around a shared vertical axis, with counter-rotation to keep images front-facing. Touch / mouse dragging, previous/next buttons, page dots, and arrow-key / Home / End navigation. Captions use a component-local 32 px black style as annotated; all three pages share it. The carousel is manually controlled with no automatic rotation.
- Product details, quick add, browser-persistent shopping bag with quantity controls, editorial reading dialogs, local demo newsletter signup.
- Reduced-motion support, keyboard focus styling, native modal dialogs, labeled controls, and mobile layouts.

The brand, products, prices, and editorial copy are illustrative. The bag and newsletter are local demos; no payments, orders, or email subscriptions are sent.
