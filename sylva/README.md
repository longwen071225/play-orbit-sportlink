# 跃星 PLAY ORBIT

面向家长和儿童的运动成长平台，电脑端 Web 本地黑客松演示实现。当前只交付电脑端网站，不开发手机端和手机专用底部导航。设计的唯一依据是 [DESIGN.md](../DESIGN.md)；后续新增页面和修改也遵循这份规范。

## 已实现

- 白底清新配色 / Liquid Chrome 首页、运动分类、教练推荐与运动知识入口。
- 教练搜索、运动 / 地区 / 年龄 / 价格筛选、价格排序、详情及课程选择。
- 演示家庭会话、孩子切换、儿童档案及可保存的运动目标。
- 规则式 AI 演示对话、目录内的教练推荐及跳转。
- 三步预约、实时演示时段、冲突校验、请求幂等、课程清单、取消与课后反馈。
- Three.js 成长宇宙、点击详情、缩放 / 旋转 / 重置、时间轴、等价记录列表、减少动态效果与 WebGL 降级。
- 独立测试教练工作台确认完课；服务端创建星星与成长事件；前端轮询同步、点亮、确认消费；刷新后保留。
- 家庭练习基础记录和可阅读运动内容。完整视频播放、练习上传 / 教练审核等 P1 功能尚未接入。

## 本地服务

`npm run dev` 启动 Vite 网页和本地 API。网页端口默认 5173，API 4311，通过 Vite `/api` 代理访问。运行时数据保存在 `.local/demo.json`，该目录已被 Git 忽略。

`npm run build` 构建网页及已有 Sites 包装；`npm run test:sites` 检查包装；`npm run test:api` 用隔离临时数据库验证业务闭环。

## 演示顺序

1. 首页选择“问问 AI 运动顾问”，进入演示家庭，选择小宇。
2. 提问“孩子想体验篮球，怎样开始？”，进入推荐的陈宇教练详情。
3. 选择课程、未来日期与可约时段，确认预约，在“我的课程”查看。
4. 从页尾进入 `/demo/coach`，输入本地测试口令，确认该测试课程完成。
5. 返回“我的课程”，等待同步（至多约 5 秒），点击新星提示进入成长星图。
6. 观看点亮，点击新星查看训练反馈，再刷新确认星星仍存在且不重复记账。

本地测试教练口令默认 `orbit-demo-2026`，可以通过 `DEMO_OPERATOR_CODE` 环境变量替换。此测试工作台只用于本机演示，不是生产权限系统。家长会话无权调用完课接口。

## 维护约定

- `src/tokens.css`：DESIGN.md 的共享颜色、字体、字号、间距基准和动效 Token。
- `src/styles.css`：基础布局与组件结构；`src/acid.css`：v2 Acid Graphic 排版、材质、响应式与动效。
- `src/App.jsx`：页面与复用组件、导航、会话和孩子上下文。
- `src/Universe.jsx`：仅负责空间渲染与节点交互，永久成长事实由 API 提供。
- `src/api.js`：所有前端网络访问统一入口；`VITE_API_BASE_URL` 可替换后端地址。
- `api/server.mjs`：本地测试数据、会话、预约、课程完成、事件与磁盘持久化。
- `AGENTS.md`：记录未来开发必须遵循的设计规范。

## 当前边界

所有人物、儿童、经验、资质、课程、费用和反馈均为合成演示数据。顾问没有连接实时 LLM，不声称生成真实专业服务；会话是本地演示会话，不是真实账号体系；预约不收取任何费用。该服务器采用串行文件持久化，适合本机演示，不用于生产并发与多家庭授权。

保留的 Sites Worker 仅提供静态网页与 SPA 路由回退，不包含本地 Node API。当前未部署；如后续发布，需要另外接入可持久化的线上后端，不能直接把静态包装描述为完整线上平台。
